# 한빛시 통합민원 플랫폼 고도화 사업 제안서 (초안 v0.3)

## 1. 사업 이해도 및 추진 전략

한빛시는 2017년 구축한 민원 포털과 12개 부서별 민원 처리 시스템이 분산되어 있어 민원인이 같은 서류를 반복 제출하고 담당자가 처리 현황을 수작업으로 취합하는 문제를 안고 있다. 당사는 민원 처리 평균 소요일 6.8일을 4일 이내로 줄이는 것을 사업 목표로 설정했다.

추진 전략은 세 가지다. 첫째, 접수 창구를 하나로 통합한다. 둘째, 외부 기관 자료를 자동으로 확인해 구비서류를 없앤다. 셋째, 처리 현황을 실시간으로 공유한다.

## 2. 기능 요구사항 구현 방안

통합 민원 접수 화면에서 온라인·방문·전화 민원을 단일 화면으로 등록하고 접수번호를 자동 부여한다. 접수 즉시 민원 내용을 분석하여 담당 부서와 민원 유형을 자동 추천하며, 추천 정확도 85% 이상을 목표로 분류 모델을 학습한다.

접수·배정·처리·결재·통지의 처리 단계를 정의하고 단계별 담당자와 처리 시각을 기록한다. 단계가 바뀌면 문자, 카카오 알림톡, 이메일 중 민원인이 선택한 채널로 통지한다.

민원인이 이전에 제출한 구비서류는 유효기간 내 재사용할 수 있게 하고 재사용 동의 이력을 남긴다. 담당자는 배정 민원, 기한 임박 민원, 반려 민원을 하나의 업무함에서 처리한다.

처리 현황 대시보드는 부서·유형·기간별 접수·처리·지연 건수를 실시간 집계하고 지연 민원을 강조 표시한다. 민원 처리 결과는 기존 문서관리시스템의 전자결재로 상신하고 결재 결과를 자동 반영한다.

월간·분기·연간 민원 통계를 자동 생성하고 엑셀과 PDF로 내려받을 수 있다. 민원 유형, 처리 단계, 기한, 담당 부서는 관리자 화면에서 코드 변경 없이 설정한다.

## 3. 시스템 아키텍처

시스템은 한빛시가 지정하는 공공 클라우드 환경에 구축하며 웹·WAS·DB를 이중화하여 단일 장애점을 없앤다. 전자정부 표준프레임워크 4.x와 공개 소프트웨어 기반 DBMS를 사용하고 기존 통합 인증(SSO) 체계를 그대로 연동한다.

## 4. 데이터 및 연계

정부24에서 신청된 민원을 실시간 수신하고 처리 결과를 회신한다. 행정정보공동이용센터 연계로 주민등록등본 등 구비서류를 자동 확인한다. 문서관리시스템과는 REST API 기반 표준 연계 방식으로 연동하고, 시 공통 문자 발송 서비스와 카카오 알림톡 서비스를 연계한다.

민원 데이터 항목은 행정안전부 공공데이터 공통표준용어를 따라 정의한다. 일 단위 증분 백업과 주 단위 전체 백업을 수행하고 분기마다 복구 시험을 실시한다.

## 5. 성능 및 보안

일반 조회 화면의 평균 응답 시간 3초 이내, 통계 화면 5초 이내를 목표로 캐시와 비동기 집계를 적용한다. 연간 서비스 가동률 99.9% 이상을 보장하기 위해 이중화 구성과 모니터링 체계를 운영한다.

사용자 역할별 접근 권한을 관리하고 모든 접근 이력을 1년 이상 보관한다. 주요정보통신기반시설 기술적 취약점 분석·평가 기준에 따라 웹 취약점을 점검하고 조치한다. 도입하는 보안 솔루션은 CC 인증 보유 제품으로 구성한다.

## 6. 사업 관리

착수 후 2주 이내에 사업수행계획서와 WBS를 제출하고 승인을 받는다. 주간 진척 보고와 월간 보고회를 실시하며 단계별 산출물 검토와 품질 점검을 수행하고 PMO 점검에 협조한다. 위험 등록부를 운영하고 월간 보고회에서 위험 현황을 보고한다.

## 7. 교육 및 지원

담당자 교육 4회와 관리자 교육 2회를 실시하고 교육 자료를 제공한다. 사용자 매뉴얼과 운영자 매뉴얼을 국문으로 작성하여 제공한다. 운영 인력에게 소스코드, 구성, 장애 대응 절차에 대한 기술 이전을 수행한다.

## 8. 수행 실적

당사는 최근 5년간 광역시 2곳과 기초자치단체 4곳의 민원 시스템 구축 사업을 수행했다.
