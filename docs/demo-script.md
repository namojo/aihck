## 예상 질문

- **LLM이 틀리면?** 모든 항목에 원문 인용과 쪽 번호가 붙어 있다. 사람이 10초 안에 확인하고 고친다. 추출 품질은 골든셋으로 측정하며(`eval/`), 프롬프트를 바꾸면 재현율 변화를 기록한다.
- **기존 Copilot·문서 요약과 다른 점은?** 요약이 아니라 추적표·목차·커버리지라는 제안 업무의 산출물을 낸다. 배점 비중으로 분량을 배분하고 초안과 대조하는 흐름은 제안 전용이다.
- **실제 RFP에서도 되나?** 데모는 가상 RFP다. 나라장터 공개 RFP로 시험할 때는 표 형식이 기관마다 달라 `parse.py`의 제목 패턴과 표 처리를 손봐야 한다. 그래서 파서를 LLM 없이 결정적으로 두고 테스트를 붙였다.
- **비용은?** 300쪽 기준 LLM 호출은 섹션 수 + 위험 조항 수 + 요구사항/12 회 정도다. 캐시(시스템 프롬프트 고정)와 체크포인트 재사용으로 재실행 비용을 줄인다.
