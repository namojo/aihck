RFP Compass

300쪽 제안요청서를 넣으면 요구사항 추적표 · 배점 기준 목차 초안 · 위험 조항 경고 · 제안서 초안 커버리지가 나온다. 모든 결과에 원문 인용과 쪽 번호가 붙는다.

데모 대시보드 열기 아이디어 기획서 (웹) 기획서 PDF GitHub 저장소

여섯 단계, LLM은 셋에서만

parsePDF → 표·섹션 (코드)
extract요구사항 구조화 (Claude)
toc배점표 탐지 + 연결
risk규칙 20개 + LLM 보강
coverage초안 ↔ 요구사항
exportxlsx · docx · html (코드)
